\section*{Data availability}

All data analysed in this study are either generated by the released
simulation code or taken from two public sources of real measurements. The
Hudson's Bay Company lynx and hare pelt counts for 1900--1920 used in the
lynx--hare case study (\SNrealdata) are the values distributed with the Stan
example models (\texttt{knitr/lotka-volterra/hudson-bay-lynx-hare.csv},
\url{https://github.com/stan-dev/example-models}) and are reproduced verbatim in
\texttt{experiments/exp12\_realdata.py}. The ocean drifter velocities used in
the drifter case study are from
the NOAA Global Drifter Program hourly product, version 2.01
(\url{https://doi.org/10.25921/x46c-3620}, licence CC BY 4.0), accessed through
\url{https://erddap.aoml.noaa.gov/gdp/erddap/index.html}; the processed subset
used here is distributed with the code (\texttt{data/}) together with the
script that regenerates it. All raw result files are in the
\texttt{results/} directory of
\url{https://github.com/Kendiukhov/certified-symmetry-discovery}; the version
used for this article is tagged \texttt{v2.0.0}.
